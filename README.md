# ТОПА

Приложение для изучения татарского, чувашского и киргизского языков.

Статический сайт: HTML, CSS и JavaScript. Сборка и установка зависимостей не требуются. GitHub Pages публикует файлы из корня репозитория.

## Что работает

- Раздел «Курсы» с выбором разговорного и изучаемого языков.
- Три урока для каждого изучаемого языка: знакомство с лексикой, приветствия и диалог в магазине, блокировка следующего до завершения предыдущего и повторное прохождение.
- Раздельный прогресс, серия и справочник изученных слов.
- Карточки повторения и обратимый массовый выбор слов урока.
- Адаптивная версия со статистикой и профилем.

Прогресс хранится в localStorage текущего браузера отдельно для каждого изучаемого языка. Разные адреса сайта и устройства не обмениваются им автоматически. Русский курс для носителей других языков пока отображается как «Скоро».

## Проверка

При установленном Node.js:

```sh
node tests/flashcards.test.cjs
node tests/streak.test.cjs
node tests/intro-lesson.test.cjs
node tests/assets.test.cjs
node tests/mobile-viewport.test.cjs
```

## Структура

`index.html` — разметка и уроки; `flashcards.*` — повторение; `mobile-layout.*` — адаптивная раскладка; `courses.*` — выбор курсов; SVG рядом — используемая графика.

## Голосовая практика · пилот

`practice.*` — окно записи и текстового разговора с Топой. Доступно для первого урока татарского. `server/` — отдельная серверная программа: Gladia распознаёт запись, Qwen через Яндекс AI Studio отвечает текстом по материалам урока. Провайдеры пока не подключены; без настройки окно сообщает об этом, вымышленные ответы не подставляются. Озвучки нет. Существующий прогресс и ключи localStorage не меняются.

Полная инструкция, переменные окружения, лимиты и ограничения пилота: [server/README.md](server/README.md). Секреты нельзя добавлять в `practice-config.js` или GitHub. Статический сайт можно оставить на GitHub Pages; Node.js 24+/FFmpeg запускаются на отдельном небольшом хосте. Для проверок сервера: `node --test tests/practice.test.mjs`.

## Ознакомительный урок

Первым на дороге стоит «Знакомство»: 10 заданий четырёх типов — выбор слова по иллюстрации, выбор перевода, сопоставление пар и сборка перевода из слов. Лексика взята из следующих уроков: магазин, пальто, тёплый, красивый, здравствуйте, спасибо и помощь.

Прежние идентификаторы уроков и слов сохранены. Ранее пройденные уроки остаются пройденными; новый ознакомительный урок можно пройти отдельно. У нового пользователя уроки открываются последовательно. Повторяющиеся слова в справочнике показываются только один раз, под первым завершённым уроком в порядке дороги. История карточек повторения сохраняется при переносе слова между группами.

`intro-lesson.css` — оформление пяти остановок дороги и заданий с иллюстрациями. `intro-coat.svg` и `intro-shop.svg` — новые иллюстрации. Для обновления замените файлы из архива проекта целиком, сохранив структуру папок.

## Загрузка графики

Все изображения и иконки — настоящие векторные SVG без встроенных растров. `asset-loading.js` предварительно загружает и декодирует графику; окно урока открывается после готовности нужных изображений. Отмена открытия и переключение курса исключают появление старого урока после окончания загрузки. Ошибка изображения не блокирует работу урока.

В ознакомительном уроке под заголовком нет поясняющей подписи, над заголовком нет нумерации задания. Счётчик и полоса прогресса сохранены в шапке урока. Иконка второго урока — буква из предоставленного образца; до разблокировки остаётся замок.

## Мобильная раскладка

`mobile-viewport.css` и `mobile-viewport.js` учитывают `visualViewport`, динамическую высоту окна и безопасные отступы телефона. «Курсы», «Статистика» и «Профиль» не прокручиваются; «Обучение» сохраняет вертикальную прокрутку. На низком экране карточки статистики располагаются в две колонки. В справочнике прокручивается список слов, а кнопка перехода к повторению остаётся внизу окна. Масштабирование жестами отключается через viewport, touch-action и обработчики жестов мобильного браузера.

Добавление/отмена слов в повторении и завершение уроков работают без всплывающих уведомлений. На лицевой стороне карточки повторения есть подпись «Нажмите, чтобы увидеть перевод». Ключи прогресса и история карточек не изменены.
