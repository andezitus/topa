# ТОПА — демоверсия озвучки самостоятельного режима

Только ветка `selfstudy-heygen-audio-demo`. В `main` никаких изменений.

- 60 выбранных записей HeyGen: 54 строки диалога (по 18 на язык), ещё 6 заданий.
- Голоса: Евгения = женщина и задания; Артём = ученик.
- При клике на спикер играется MP3, а не браузерный синтез речи (в самостоятельном режиме).
- Русскоязычный вводный сценарий и корпоративный режим не затронуты.
- При недоступности MP3 остаётся запасное воспроизведение средствами браузера.
- 6 утверждённых срезов пока применяются при воспроизведении по длительности: Татарский 3 −0,46 с, 8 −0,28 с; Чувашский 5, 7 −0,42 с; Кыргызский 7 −0,42 с, 12 −0,44 с.
- Ссылки HeyGen могут истечь: для постоянной независимой сборки необходимо сохранить MP3 в репозиторий.
- Скрипт `python scripts/import_selfstudy_audio.py` скачивает все записи в `selfstudy-assets/audio/` и физически обрезает шесть, не меняя остальные 54. Нужны ffmpeg/ffprobe и интернет, исходники сохраняются отдельно.
- После успешной загрузки файлов переключить `let useLocal = false;` в `selfstudy-audio.js` на `true`.
- Проверка кода в ветке **не заменяет** проверку аудио в работающем браузере.

Интеграция: `index.html` вызывает `TopaSelfStudyAudio.play` только в самостоятельном режиме (не во вводном уроке); `selfstudy-audio.js` по индексу диалога использует правильный голос и файл. Остальные обработчики уроков сохранены.

## Автоматический импорт

Workflow `.github/workflows/import-selfstudy-audio.yml` запускается при добавлении workflow в ветку и вручную по `workflow_dispatch` (если доступен в GitHub Actions). Он скачивает 60 MP3, применяет 6 утверждённых срезов через ffmpeg и сохраняет бинарные файлы **только** в демо-ветку. Успех нужно проверить по наличию `selfstudy-assets/audio/import_report.json`; до подтверждения проверка аудио продолжает работать через ссылки HeyGen.
